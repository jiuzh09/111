# 力学实验室：人船、板块与传送带

一个轻量、无需构建工具的中文高中物理交互网页，用于探索人船动量守恒、水平传送带和板块模型中的运动过程。

## 使用

直接在浏览器打开 `index.html`。在顶部选择人船、传送带或板块模型，修改参数后点击“重新计算”，再使用播放按钮或时间轴观察运动、相对滑动和动量变化。

## 功能

- 人船模型：设置人的质量、船的质量、船的长度和人的相对速度。
- 人船模型展示动量守恒，并将人的位置、船的位置和相对速度以动画呈现。
- 传送带模型：设置物块初始状态、摩擦因数和传送带速度。
- 板块模型：设置木板质量、初速度以及木板与地面的摩擦。
- 动画、实时数据和运动图像共享同一组数值积分结果。
- 响应式布局，可在手机与桌面浏览器使用。

这是独立实现的学习演示，采用离散时间步近似；结果适合直观学习，不替代严格解析计算。
