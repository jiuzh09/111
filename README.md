# 力学实验室：板块与传送带

一个轻量、无需构建工具的中文高中物理交互网页，用于探索水平传送带与板块模型中的运动过程。

## 使用

直接在浏览器打开 `index.html` 即可。修改左侧参数后点击“重新计算”，使用播放按钮或时间轴观察物块运动；页面同时绘制位置—时间和速度—时间图像。

## 功能

- 传送带模型：设置物块初始状态、摩擦因数和传送带速度。
- 板块模型：设置木板质量、初速度以及木板与地面的摩擦。
- 动画、实时数据和运动图像共享同一组数值积分结果。
- 响应式布局，可在手机与桌面浏览器使用。

这是独立实现的学习演示，采用离散时间步近似；结果适合直观学习，不替代严格解析计算。
